# TutorRoster

[![Java CI](https://github.com/AY2627S1-CS2103T-T15-2/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-T15-2/tp/actions/workflows/gradle.yml)
[![codecov](https://codecov.io/github/AY2627S1-CS2103T-T15-2/tp/graph/badge.svg?token=HPP99QLK41)](https://codecov.io/github/AY2627S1-CS2103T-T15-2/tp)

![Ui](images/Ui.png)

**TutorRoster is a desktop app for independent private tutors to manage the contact details of their students and the students' guardians.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using TutorRoster, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing TutorRoster, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
